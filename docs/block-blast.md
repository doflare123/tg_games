# Block Blast

Поле 8×8; фигуры не вращаются. Нужно разместить тройку целиком, чтобы получить следующую.
Полные строки и столбцы очищаются одновременно. Очки за ход: число поставленных блоков
плюс 10 × число очищенных линий², плюс 100, если поле стало пустым. Пересечение считается
двумя линиями. Лучший счёт одной завершённой партии определяет место в рейтинге.

Каждая новая тройка имеет как минимум одну последовательность размещения всех трёх фигур.
Генератор детерминированно строит 16 допустимых последовательностей и выбирает более
ограниченную и разнообразную комбинацию: предпочтение фигурам, которые освобождаются
после очистки линий. Порядок выдачи перемешивается. Свидетель решения не хранится в
состоянии партии. Генерация ограничена по времени работы, без бесконечных попыток.
Если крупные фигуры не помещаются, используется одиночный блок; на стабильном поле
есть свободная клетка, а заполнение последней свободной клетки обязательно очищает линию.
Ошибочное размещение может перекрыть решение. Игра заканчивается, когда ни одна
оставшаяся фигура не помещается; также можно добровольно завершить партию.

Сервер создаёт seed и авторитетное состояние. `submitBlockMoves` принимает только
координаты, слоты, ревизию и признак завершения, воспроизводит ходы и вычисляет очки.
Идентичность берётся из проверенного Telegram-контекста. CAS защищает ревизии;
повтор того же запроса после потери ответа возвращает уже сохранённый результат.
Партия действует 24 часа, пакет ограничен 24 ходами. Клиент сохраняет ожидающий
пакет и ключ создания на устройстве для повторной отправки.

`getBlockLeaderboard` поддерживает общий рейтинг и группы с проверкой участия,
периоды all/week (понедельник UTC, по началу партии). Один лучший результат на игрока;
при равных очках выше более ранняя партия, затем id. Сервер сохраняет лучший результат
и за пределами топ-50. Групповые рекорды проходят общую очередь уведомлений:
настройки группы, проверка членства, проверка актуальности рекорда, идемпотентный
ключ, повторы доставки, общий межигровой интервал 5 минут, тема группы.

`schema.ts` содержит таблицу `block_blast_runs`. Сборка и тесты не мигрируют рабочую БД.
Для локальной проверки: `npm run check`, `npm run test:block-blast:browser`;
после сборки доступен вариант `npm run test:block-blast:browser -- --production`.
