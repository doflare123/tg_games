# Группы, команды и мобильное управление

## Управление

Тетрис управляется жестами на поле: тап — поворот по часовой стрелке; горизонтальный свайп/перетаскивание — движение по клеткам; удержание от 220 мс — ускоренный спуск до отпускания; быстрый свайп вниз — один мгновенный сброс. Медленное движение вниз включает ускорение. Для HOLD оставлена отдельная кнопка, на клавиатуре — F или C (физические клавиши работают и в русской раскладке). После нажатия кнопок во время игры фокус возвращается на поле, поэтому стрелки и пробел продолжают управлять фигурами. Второй палец не перехватывает активный жест; отмена касания, пауза и закрытие освобождают ускорение. Скролл и long-press меню на поле отключены, снаружи поля прокрутка сохраняется.

Используется готовая nipplejs 1.0.4. В Doom левый стик двигает вперёд/назад и делает стрейф; полное отклонение включает бег. Правый стик поворачивает камеру по горизонтали — классический движок Doom не поддерживает вертикальный свободный обзор. Огонь и действие находятся отдельно, меню/оружие/карта/сохранения — на компактной панели.

В Mario — левый стик и стандартные A/B справа, SELECT/START снизу. Одновременные удержания разделены по источникам: отпускание кнопки не отпускает стик. При потере фокуса, отмене касания и закрытии игры нажатия освобождаются. Клавиатура и NES-геймпад сохраняются.

## Группы

Бот не получает полный список Telegram-групп человека. В «Мои группы» появляются подключённые к боту группы после подтверждения участия через Telegram, даже если пользователь ещё не писал там команды. За один запрос проверяется до 50 групп с приоритетом ранее известных участий. Для группового рейтинга бот должен быть администратором. Перед возвратом названий/рейтинга и сменой настроек участие проверяется через getChatMember; роль администратора проверяется отдельно. Клиентский groupId не даёт доступа.

Групповой рейтинг — лучшие результаты текущих подтверждённых участников, в том числе партии до подключения бота и помеченные ручные корректировки. Игровые записи не копируются и не переписываются. При подключении бота и открытии рейтинга сверяются известные боту игроки с результатами: до 24 проверок за вызов, по 4 параллельно. Кэш сверки действует до 15 минут; chat_member обновляет участие сразу. Большая сверка продолжается следующими запросами, интерфейс показывает прогресс и обновляет таблицу. При ошибке Telegram устаревшие неподтверждённые записи не показываются, доступна повторная сверка. Ушедший участник пропадает из рейтинга этой группы; глобальные результаты остаются. Полный список участников Telegram не перебирается — проверяются известные игроки.

Для объявлений проверяются подключённые группы игрока на момент завершения партии. Пустой список групп в стартовом снимке Тетриса не мешает объявить новый рекорд. Добавление участника или новой группы не создаёт объявлений о прошлых результатах: учитывается время включения уведомлений. Перед расчётом и отправкой сверяется текущий состав группы.

## Команды

- /game_tetris, /game_minesweeper, /game_2048, /game_snake — прямая ссылка на соответствующую игру. У Змейки общий рейтинг с отдельными таблицами по размеру поля. Объявления первого рекорда, улучшения лидером и обгона в топ-10 используют общую настройку уведомлений группы; сравниваются только её участники. Кнопка открывает размер поля рекорда.
- /game_top — рейтинг текущей группы.
- /game_notify_on, /game_notify_off — управление объявлениями, только для администраторов группы.
- /game_notify_here — включить объявления и отправлять их в тему, где вызвана команда. Только для администраторов группы. Для смены темы вызовите команду в другой теме; в «Общем» или обычной группе она возвращает отправку в общий чат. Номера чатов и тем вводить не нужно.
- /games — каталог.

Команды регистрируются как нативные ephemeral-команды Bot API 10.2+. Ответ отправляется через ephemeral_message_parameters.receiver_user_id; ответ на ephemeral-команду содержит reply_parameters.ephemeral_message_id. Публичного fallback для неудавшегося приватного ответа нет.

Меню конкретной группы регистрируется при my_chat_member. Для уже добавленных групп можно выполнить npm run configure:bot после CLI login; это обращение к живому боту. Сама сборка меню не регистрирует. В старом клиенте или при отправке обычного сообщения вместо нативной ephemeral-команды текст запроса может оставаться публичным. Скрытие команды задним числом не обещается.

На текущем этапе не делаем минутное удаление и не запускаем внешний worker — пользователь отложил эту возможность. Ephemeral-сообщения исчезают по правилам клиента Telegram; гарантированного TTL 60 секунд здесь нет.

## Объявления

По умолчанию выключены. Администратор включает их командой или кнопкой в выбранном групповом рейтинге.

Тему выбирает администратор командой `/game_notify_here` непосредственно в нужной теме. Команда одновременно включает объявления; подтверждение видно только вызвавшему её пользователю и приходит в ту же тему. `/game_notify_on`, `/game_notify_off` и переключатель в приложении сохраняют выбранную тему. Ответы на остальные команды также остаются в теме вызова. Место отправки хранится в `groups.notification_thread_id` (NULL — общий чат), сохраняется после перезапуска и не меняется при обновлении прав бота. Используются поля [Message](https://core.telegram.org/bots/api#message) `is_topic_message` и `message_thread_id` и параметр [sendMessage](https://core.telegram.org/bots/api#sendmessage) `message_thread_id`.

Все игры используют одну тему и прежний лимит одного объявления на группу за пять минут. Смена темы не сбрасывает лимит и не создаёт новые задания. Очередь, включая повторы, использует тему, выбранную на момент отправки. При недоступной или удалённой теме действует обычный ограниченный механизм повторов; публичного перенаправления в общий чат нет. Администратор может выбрать доступную тему той же командой.

Перед использованием в существующем облачном окружении требуется отдельно применить изменение схемы `groups.notification_thread_id` через штатный `npm run cloud:migrate` и обновить меню через `npm run configure:bot`. Эти команды обращаются к живому боту; build/test их не выполняют. До обновления меню доступна текстовая команда `/game_notify_here@имя_бота` после публикации кода и применения схемы. Доставка в настоящую Telegram-тему требует отдельной проверки на тестовом боте.

Объявления работают для 2048, Тетриса и каждого размера Сапёра отдельно, по рейтингу конкретной группы: первый результат в пустой таблице, улучшение рекорда группы (включая улучшение самим лидером) или обгон соперника с улучшением места в топ-10. Личные рекорды на прежнем месте вне первого и изменения только глобального рейтинга не создают сообщение. Ручные корректировки объявлений не создают. Текст содержит игру/режим, результат, соперника, разницу и переход между местами. В конце — «Хочешь побить рекорд? Заходи играть!» и кнопка «🎮 Побить рекорд», которая открывает ту же игру и режим или размер поля.

У завершений есть атомарно назначаемый порядок. Позиции до/после рассчитываются по историческому префиксу этого порядка, поэтому поздняя обработка не включает будущие результаты. Событие имеет стабильный id. Перед отправкой проверяются актуальность рекорда, участие и включённая настройка; действует ограничение одного объявления на группу за пять минут.

SQL-outbox использует lease и счётчик попыток; 429 учитывает retry_after. Повтор той же доставки сохраняет резерв cooldown. Pending-эффекты восстанавливаются из сохранённых результатов обеих игр; сбой одного результата не блокирует обработку остальных. Основной запуск — в endpoint завершения партии; после ошибки повтор происходит при следующих вызовах обработки либо вручную через служебный CLI endpoint maintenance. Постоянного планировщика сейчас нет. После пяти минут устаревшие объявления подавляются.

Telegram не предоставляет идемпотентную отправку: при сбое между отправкой и фиксацией её успеха редкий повтор сообщения возможен. Сохранение результата от доставки не зависит. В 2048 порядок результатов фиксируется по завершению партии; старые результаты при миграции остаются без повторных объявлений. Настройка /game_notify_on и общий пятиминутный лимит группы действуют для всех трёх игр. Объявления 2048 во время этого лимита остаются в очереди до следующей обработки; окно доставки — сутки от создания задания. Для новых правил с ростом плиток и старой классики используются отдельные таблицы результатов. Повторы запускаются запросами игры и открытиями приложения; автономного worker нет.

Mario/Doom пока скрыты из каталога. Актуальные native-команды и доставка в реальной группе требуют проверки на подключённом тестовом боте.

Источники: [ephemeral API](https://core.telegram.org/bots/api#ephemeral-messages-and-commands), [getChatMember](https://core.telegram.org/bots/api#getchatmember), [Mini App deep links](https://core.telegram.org/bots/webapps#direct-link-mini-apps).

## Если бот молчит или ссылка не открывается

`npm run diagnose:bot` читает getMe, меню all_group_chats и текущие права в первых 10 сохранённых группах. `hasMainMiniApp: false` означает, что прямые групповые ссылки `?startapp` ещё не готовы: включите Main Mini App в BotFather и задайте публичный HTTPS URL из `npm run cloud:status`. В личке web_app-кнопка открывает этот URL непосредственно. Групповой запасной переход `?start` сохраняет игру, но требует открыть личку и запустить бота.

Пустое меню исправляется `npm run configure:bot` (изменяет только регистрацию команд). При Privacy Mode обычная `/game_tetris` без адреса может не доставляться. Используйте меню либо `/game_tetris@имя_бота`; для полноценных групповых функций назначьте бота администратором. Сервер не может ответить на обновление, которое Telegram ему не прислал. Права группы повторно приходят через my_chat_member.

## Ручные корректировки

Служебный CLI endpoint recordManualResult хранит корректировку отдельно от проверенных партий в manual_results: автор операции, основание, точность счёта и известное время. В рейтинге она явно помечена «вручную», приблизительный счёт — знаком ≈. Отсутствующее время хранится NULL, при равенстве очков уступает известному времени. Для Sprint корректировка без точного времени не допускается. Ключ операции идемпотентен; другая запись с тем же id отклоняется. Группы проверяются отдельно. Корректировка не создаёт replay и не рассылает объявлений.
