# Группы, команды и мобильное управление

## Управление

Используется готовая nipplejs 1.0.4. В Doom левый стик двигает вперёд/назад и делает стрейф; полное отклонение включает бег. Правый стик поворачивает камеру по горизонтали — классический движок Doom не поддерживает вертикальный свободный обзор. Огонь и действие находятся отдельно, меню/оружие/карта/сохранения — на компактной панели.

В Mario — левый стик и стандартные A/B справа, SELECT/START снизу. Одновременные удержания разделены по источникам: отпускание кнопки не отпускает стик. При потере фокуса, отмене касания и закрытии игры нажатия освобождаются. Клавиатура и NES-геймпад сохраняются.

## Группы

Бот не получает полный список Telegram-групп человека. В «Мои группы» появляются только известные боту группы, где пользователь обнаружен через команду или обновление членства. Для группового рейтинга бот должен быть администратором. Перед возвратом названий/рейтинга и сменой настроек участие проверяется через getChatMember; роль администратора проверяется отдельно. Клиентский groupId не даёт доступа.

При старте ranked-run сервер фиксирует до 50 подтверждённых подключённых групп. Результат учитывается глобально и в этих группах; прежние глобальные партии не проецируются в новую группу. Исторические результаты, полученные во время участия, сохраняются в таблице группы после ухода игрока, но ушедший пользователь теряет доступ к ней. Отправка объявления дополнительно проверяет текущее участие.

## Команды

- /game_doom, /game_mario, /game_tetris — прямая ссылка на соответствующую игру.
- /game_top — рейтинг текущей группы.
- /game_notify_on, /game_notify_off — управление объявлениями, только для администраторов группы.
- /games — каталог.

Команды регистрируются как нативные ephemeral-команды Bot API 10.2+. Ответ отправляется через ephemeral_message_parameters.receiver_user_id; ответ на ephemeral-команду содержит reply_parameters.ephemeral_message_id. Публичного fallback для неудавшегося приватного ответа нет.

Меню конкретной группы регистрируется при my_chat_member. Для уже добавленных групп можно выполнить npm run configure:bot после CLI login; это обращение к живому боту. Сама сборка меню не регистрирует. В старом клиенте или при отправке обычного сообщения вместо нативной ephemeral-команды текст запроса может оставаться публичным. Скрытие команды задним числом не обещается.

На текущем этапе не делаем минутное удаление и не запускаем внешний worker — пользователь отложил эту возможность. Ephemeral-сообщения исчезают по правилам клиента Telegram; гарантированного TTL 60 секунд здесь нет.

## Объявления

По умолчанию выключены. Администратор включает их командой или кнопкой в выбранном групповом рейтинге.

Объявление создаётся только после проверки партии и при выполнении всех условий: новая лучшая попытка игрока, улучшение позиции до/в пределах топ-10 и обгон хотя бы одного соперника. Просто улучшение своих очков на прежнем месте и первое место в пустой таблице не создают сообщение. Текст содержит игру/режим, результат, соперника, разницу и переход между местами.

У завершений есть атомарно назначаемый порядок. Позиции до/после рассчитываются по историческому префиксу этого порядка, поэтому поздняя обработка не включает будущие результаты. Событие имеет стабильный id. Перед отправкой проверяются актуальность рекорда, участие и включённая настройка; действует ограничение одного объявления на группу за пять минут.

SQL-outbox использует lease и счётчик попыток; 429 учитывает retry_after. Повтор той же доставки сохраняет резерв cooldown. Pending-эффекты восстанавливаются из проверенных результатов. Основной запуск — в endpoint завершения партии; после ошибки повтор происходит при следующих вызовах обработки либо вручную через служебный CLI endpoint maintenance. Постоянного планировщика сейчас нет. После пяти минут устаревшие объявления подавляются.

Telegram не предоставляет идемпотентную отправку: при сбое между отправкой и фиксацией её успеха редкий повтор сообщения возможен. Сохранение результата от доставки не зависит.

Рейтинги и объявления пока работают для проверяемых результатов Tetris. Для Mario/Doom они будут доступны после реализации их серверной проверки. Актуальные native-команды и доставка в реальной группе требуют проверки на подключённом тестовом боте.

Источники: [ephemeral API](https://core.telegram.org/bots/api#ephemeral-messages-and-commands), [getChatMember](https://core.telegram.org/bots/api#getchatmember), [Mini App deep links](https://core.telegram.org/bots/webapps#direct-link-mini-apps).

## Если бот молчит или ссылка не открывается

`npm run diagnose:bot` читает getMe, меню all_group_chats и текущие права в первых 10 сохранённых группах. `hasMainMiniApp: false` означает, что прямые групповые ссылки `?startapp` ещё не готовы: включите Main Mini App в BotFather и задайте публичный HTTPS URL из `npm run cloud:status`. В личке web_app-кнопка открывает этот URL непосредственно. Групповой запасной переход `?start` сохраняет игру, но требует открыть личку и запустить бота.

Пустое меню исправляется `npm run configure:bot` (изменяет только регистрацию команд). При Privacy Mode обычная `/game_tetris` без адреса может не доставляться. Используйте меню либо `/game_tetris@имя_бота`; для полноценных групповых функций назначьте бота администратором. Сервер не может ответить на обновление, которое Telegram ему не прислал. Права группы повторно приходят через my_chat_member.
