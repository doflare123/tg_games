# Модерация рейтинга

`scripts/moderate-ranking.ts` работает через авторизованный management `/run` и не
публикует endpoint или новую версию приложения. Нужен CLI access token проекта в
`.tgcloud/credentials` или `TGCLOUD_TOKEN`.

Сначала установить Telegram ID по сохранённым данным. Имя — дополнительная проверка,
блокировка привязана к ID и сохраняется при смене имени. Пример проверки без изменений:

```powershell
node --experimental-transform-types scripts/moderate-ranking.ts '{"playerId":123,"expectedName":"Игрок","reason":"Запрос владельца","removeGames":["2048","minesweeper"]}'
```

Для применения добавить `--apply`. Инструмент сначала сохраняет полные удаляемые
строки и задания объявлений в игнорируемый Git каталог `.cache/ranking-moderation/`.
Затем он явно создаёт таблицу `ranking_blocks` и постоянные SQLite triggers, вносит
блокировку, отменяет ожидающие объявления игрока и удаляет его записи только из
выбранных игр. Повторный запуск безопасен; после применения сохраняется отдельный
отчёт. Сборка и тесты не вызывают этот инструмент и не меняют production БД.

Блок действует на новые рейтинговые INSERT/UPDATE во всех текущих играх: 2048,
Сапёр, Тетрис, Змейка, Flappy Bird, Block Blast, а также ручные результаты.
Удаление через `removeGames` поддерживает `2048`, `minesweeper` и `block-blast`.
Блок закрывает и завершение партий,
начатых до блокировки. Другие игроки и прежние результаты в невыбранных играх
сохраняются. Рейтинговый запрос заблокированного игрока получает SQL-ошибку
`RANKING_BLOCKED`; отдельного интерфейса управления блокировками пока нет.

Список блокировок читается из `ranking_blocks`; определения triggers — из
`sqlite_master` по префиксу `ranking_block_`. При добавлении новой таблицы результатов
нужно расширить `RANKED_TABLES` в `src/server/platform/ranking-moderation.ts` и явно
установить новые triggers служебным инструментом. Снятие блокировки требует отдельного
авторизованного удаления строки `ranking_blocks` по точному `player_id`; удалённые
результаты автоматически не восстанавливаются.
